# Визуальный референс нодового редактора

Этот каталог содержит HTML-прототип и ресурсы визуального handoff. Это справочный материал, а не production-приложение и не описание текущих API/архитектуры.

Текущий продукт построен на Svelte 5/SvelteKit, Electron и Python/FastAPI. Из прежнего README удалено ошибочное упоминание .NET. Актуальные сведения:

- [Сценарии и ноды](../docs/NODES.md).
- [Архитектура](../docs/ARCHITECTURE.md).
- [Проверенный интерфейс и замечания](../docs/AUDIT.md).
- [План улучшений](../docs/ROADMAP.md).

При использовании прототипа сверять текущие node/port contracts, responsive-поведение, сохранение и выбор Claude/GPT. Прототип не разрешает менять бизнес-логику ради внешнего совпадения.

Прежний полный handoff README сохранён в локальном архиве `artifacts/docs-refresh-2026-09-06/previous-documentation.zip` под исходным путём. HTML и остальные ресурсы каталога сохранены.

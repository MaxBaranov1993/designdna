# Handoff: Редизайн нодового редактора DesignDNA

## Overview
Полный редизайн desktop-приложения DesignAI / DesignDNA (SvelteKit + .NET монорепо `desingaiweb`):
граф нод, контекстное меню создания ноды, DNA Editor, панель Design System / UI Kit и
Motion Editor (видеоредактор с кейфреймами). Цель редизайна — снять перегруз мелким текстом,
сделать читаемым поток данных между нодами, показать статус выполнения и разгрузить топбар.

## About the Design Files
Файл `DesignDNA Node Editor.dc.html` в этом бандле — **дизайн-референс, сделанный в HTML**.
Это прототип: он показывает задуманный внешний вид, плотность, состояния и поведение, но
**не является production-кодом для копирования**. Задача — воспроизвести эти экраны в
существующей среде проекта: **Svelte 5 (runes) + SvelteKit**, в тех же компонентах и с тем же
стором (`frontend/src/flow/store.ts`), используя `frontend/src/index.css` и `editor/editor.css`
как места для стилей. Логику (`flow/*`, `editor/controller.ts`, API-вызовы) менять не нужно —
меняется только представление, плюс перечисленные ниже точечные расширения данных.

Прототип открывается в браузере как обычная страница. Мышь: ПКМ на канвасе — меню создания ноды,
колесо — зум, drag фона или средняя кнопка — панорама, drag шапки ноды — перемещение.

## Fidelity
**High-fidelity.** Финальные цвета, типографика, отступы, радиусы, состояния и анимации.
Значения ниже — точные, воспроизводить пиксель-в-пиксель средствами существующего CSS проекта.

### Типографика
- Семейство: **Manrope** (variable, Latin + Cyrillic), веса только **500 / 600 / 700**.
- Заголовок ноды 13px/700, letter-spacing −0.01em; подзаголовок 10.5px/600.
- Микро-лейбл (капслок) 10px/700, letter-spacing 0.06em, цвет `#8A8A93`.
- Значения полей 12–12.5px/600; статы 14px/700 (−0.02em); подписи портов 10px/600.
- Панели: заголовок секции 11px/700, letter-spacing 0.08em, `#7E7E88`.
- Табличные числа — `font-variant-numeric: tabular-nums` (время, трансформации).

### Форма и тень
- Радиусы: нода **14px**, карточка/панель 11–14px, контрол **8px**, мелкий чип 6–7px, пилюля **999px**.
- Тень ноды: `0 8px 26px rgba(0,0,0,.42)`; выбранной: `0 0 0 3px <accent>26, 0 14px 40px rgba(0,0,0,.55)`.
- Дропдаун/меню: `0 20px 60px rgba(0,0,0,.6)` + `backdrop-filter: blur(12px)`, фон `rgba(16,16,20,.97)`.
- Кадр Motion: `0 18px 50px rgba(0,0,0,.5)`.

### Сетка и размеры
- Шаг 4px. Левая панель графа **264px**, инспектор графа **312px**.
- DNA Editor: слои **256px**, инспектор **320px**.
- Motion: проект **250px**, инспектор **318px**, таймлайн-панель **250px** по высоте, колонка имён слоёв **216px**.
- Топбар 56px, вторая полоса 52px. Мин. ширина приложения 1180px (ниже — горизонтальный скролл, чрома не переносится: `white-space: nowrap` + `flex-shrink: 0` на группах).
- Нода: ширина 300–334px, шапка 12–13px паддинг, тело gap 10px.
- Порты: диаметр 10px, шаг **24px**; вход — центр на левой кромке, `top = 65 + i*24`; выход — центр на правой кромке, `top = h − 26 − i*24`. **Подписи входов выносятся ЗА левый край ноды** (`right: calc(100% - 5px)`, label слева от точки) — иначе текст наезжает на поля.

### Анимации
- Провода: две дуги — сплошная `opacity .75` + бегущий пунктир `stroke-dasharray: 3 21`, `@keyframes` сдвиг `-24` за 1.2s linear infinite.
- Пульс статуса: opacity .35 → 1 → .35, 2s ease-in-out infinite.
- Ховеры/выделение: 0.15s ease. Панель слоёв сворачивается по `width` 0.18s ease.

## Interactions & Behavior
- **Граф:** ПКМ — меню создания; drag шапки — перемещение ноды; левый drag фона и **средняя кнопка** — панорама; колесо — зум (0.3–2); клик — выбор (инспектор); «Всё» — fit; «+ Вход» — динамический порт (и вес для Микса).
- **Микс:** ±10 на весах с нормализацией суммы к 100; ±1 на количестве вариантов (1–8), статус ноды показывает `входы → варианты`.
- **DNA Editor:** клик по слою — выбор; drag объекта — перемещение с привязкой к сетке (Alt — без привязки); хоткеи V/H/F/R/O/L/I/T; зум колесом; средняя кнопка или инструмент «Рука» — панорама.
- **Motion:** Play/Pause (интервал 50мс, ~20 к/с превью, стоп в конце), перемотка кликом по любому лейну/линейке, выбор композиции табом, drag слоя пишет значение в ближайший предшествующий кейфрейм выбранного свойства, «◆ Добавить» ставит кейфрейм на плейхеде (удаляя дубль в ±30мс), «Убрать» снимает кейфрейм в ±120мс (минимум один остаётся).
- Интерполяция кейфреймов: линейная при `easing = linear`, иначе smoothstep (`u<.5 ? 2u² : 1−(−2u+2)²/2`). Позиция интерполируется как `[x, y]`.

Иконки — юникод-глифы прототипа (`⌁ ◈ ⬚ ▤ ⊕ ✦ ↳ ↔ REC M`), совпадающие с `NODE_DEFS.icon` в `flow/ports.ts`; при внедрении заменить на line-SVG 24×24, stroke 1.8–2.2, round caps (Lucide / Feather) там, где это иконки интерфейса, а не идентификаторы типов нод.

## Files
- `DesignDNA Node Editor.dc.html` — прототип всех пяти экранов (единый файл, открывается в браузере).

## Screen map: экран → файлы репозитория
| Экран прототипа | Файлы в `desingaiweb/frontend/src` |
|---|---|
| Граф, канвас, провода, панорама/зум | `FlowCanvas.svelte`, `index.css` (.fnode, .port-dot, wire) |
| Топбар / полоса контекста / зум | `App.svelte` или обёртка канваса, `index.css` |
| Левая панель (страницы, bridge) | `PagesPanel.svelte` |
| Меню «Создать ноду» | `FlowCanvas.svelte` + `flow/ports.ts` (`CTX_ITEMS`, `NODE_DEFS`) |
| Ноды и их содержимое | `nodes/*Node.svelte`, `nodes/InPorts.svelte`, `nodes/OutPorts.svelte`, `nodes/portKind.ts` |
| Нода Микс (веса, варианты) | `nodes/MixNode.svelte`, `flow/ports.ts` (`defaultData('mix')`) |
| Ноды Редактор / Страница (динамические входы) | `nodes/EditNode.svelte`, `nodes/PageNode.svelte`, `flow/ports.ts` (`portsOfNode`) |
| DNA Editor: рейка, привязка, ручные правки | `editor/CanvasStage.svelte`, `editor/ToolRail.svelte`, `editor/controller.ts`, `editor/inspector/SharedInspector.svelte`, `editor/editor.css` |
| Design System / UI Kit | `editor/DesignSystemPanel.svelte`, `editor/SourceArtifactPanel.svelte` |
| Motion Editor | `nodes/MotionWorkspace.svelte`, `nodes/motion-utils.ts`, `flow/types.ts` (`MotionNodeData`), `index.css` (.motion-*) |

## Что НЕ менять
Логику стора и API (`flow/store.ts`, `flow/api.ts`, `flow/serialize.ts`, `editor/controller.ts`),
контракты портов и типы IR. Редизайн — только представление плюс перечисленные выше поля состояния.

# Изображения и удаление фона

В ноде **Изображение** режим **GPT Image** создаёт растровое изображение через
встроенный генератор подключённого аккаунта Codex. В параметрах выбираются PNG
или JPEG. Промпт можно написать в инспекторе или подключить отдельной нодой.
Вход «референс» принимает картинку из «Референс», «Изображение» или «Удалить фон».
Размер в режиме GPT Image — пожелание модели; результат показывает фактические
размеры. JPEG сохраняет прозрачные области на белом фоне.

Старые ноды остаются в режиме **SVG**, с прежним выбором Codex/Claude.
Переключение на GPT Image выполняется явно. Новые ноды используют GPT Image.

**Удалить фон** принимает изображение по проводу или загруженный PNG/JPEG/WebP.
Провод имеет приоритет. Дополнительный текст уточняет, какой объект сохранить.
GPT Image строит чёрно-белую маску; сервер применяет её к исходным пикселям,
сохраняя размеры, цвета и существующую прозрачность. Выход — PNG с настоящим
альфа-каналом. Можно сравнить оригинал и результат, выбрать один из последних
четырёх вариантов, скачать PNG или передать его дальше по графу.

Маска модели может ошибаться на тонких деталях и границах: результат нужно
визуально проверить. Неподходящая цветная/пустая маска, неверные пропорции и
отсутствие прозрачности возвращают ошибку, сохраняя предыдущий результат.

GPT Image требует актуального desktop main/preload и авторизованного Codex CLI
с `image_generation`. Отсутствие подключения не приводит к скрытой подмене SVG
или вызову API с ключом. Генерация использует лимиты подписки Codex.

Контракт desktop: `providers:image-request` → `CodexAppServer.generateImage` →
нативный `imageGeneration` item. Текстовый ответ модели не считается картинкой.
`/api/image/convert` проверяет и кодирует PNG/JPEG;
`/api/image/remove-background` проверяет маску и применяет её к исходнику.
Отмена адресуется только текущему запросу провайдера. Смена страницы или входа
во время ожидания не позволяет записать устаревший результат в новую ноду.

Официальная документация: https://learn.chatgpt.com/docs/image-generation

В поле «Модель» выбирается модель подключённого аккаунта из локального каталога.
Для SVG выбор передаётся Codex/Claude, для растрового режима — модели Codex,
которая вызывает GPT Image. Это не переключатель версии самого GPT Image.
Выбор для SVG и растрового режима хранится отдельно; пустой выбор сохраняет
маршрут по умолчанию. При смене аккаунта выбор SVG-модели сбрасывается.

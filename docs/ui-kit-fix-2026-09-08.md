# UI Kit goslink.ru: приёмка завершена

8 сентября 2026. Система `ds-3b49622e19ab`, опубликованная ревизия **1**: **8 принятых мастеров, 0 на доработке**. Статус прочитан из реестра после завершения реального desktop AI-прохода.

## Причины и исправления

- Импортёр ошибочно сопоставлял FontFace и сетевые URL по порядку загрузки: Open Sans ссылался на файл Font Awesome. Теперь недоступные через CSSOM CDN-стили читаются по их CSS-декларациям, без догадок по resource timing. Сохранён запас для выбора используемых весов и подмножеств на сервере.
- Рендерер загружал Google Fonts поверх локальных шрифтов Source. Добавление веса 500 меняло исходное сопоставление с захваченным 400, ширины глифов, переносы и обрезание. Захваченные семейства исключены из внешнего каталога; fidelity-рендер работает с локальными шрифтами.
- В трёх отклонённых мастерах восстановлены точные файлы шрифтов из CSS сайта. В `article-card-review-5` ширина подписи возвращена с 204.86 к измеренным Source 179.86 px. В `article-card-review-4` восстановлена родительская поверхность `#f2f3f4` для отдельной строки списка.
- Тексты, состав узлов и sourceKey сохранены. Пять ранее принятых masterIr и masterHash сравнены с резервной копией и не изменились. Source-нода не редактировалась.

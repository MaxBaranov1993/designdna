## Фаза 2. Скорость воспринимаемая и реальная (P0–P1)

### 2.1 Прогресс длинных AI-операций через SSE (P0)
- Сделано: `GET /api/runs/{runId}/events` публикует стадии Generate/Quality Pass как SSE. `run_registry` ждёт изменений через condition/revision без цикла опроса; `EventSource` в web обновляет ноду, polling остался fallback. Desktop использует свой IPC-канал и не открывает SSE.
- Эффект: главный источник «программа зависла?» исчезает ещё до стриминга.

### 2.2 Стриминг ответов LLM (P1)
- Сделано: Responses-запросы генератора отправляются с `stream=true`; транспорт разбирает `response.output_text.delta`, ошибки и обязательный `response.completed`. Дельты агрегируются порциями и публикуются как `receivedChars` через SSE из 2.1, поэтому нода сразу показывает, что ответ реально поступает. Отмена web-запуска закрывает upstream-stream на следующей дельте.
- Граница безопасности: незавершённый JSON не передаётся в renderer и не попадает в состояние проекта. Только полный ответ после `response.completed` идёт в прежние `extract_json` → schema validation → autofix.
- Следующий эффект — первые визуальные изменения артборда — относится к 2.3: нужен schema-aware incremental renderer, а не рендер сырого обрезанного JSON.

### 2.3 Инкрементальный рендер артборда (P0 для редактора)
- Сделано: renderer хранит состояние каждого контейнера в `WeakMap`, сравнивает дерево по стабильным `data-ir-path` и заменяет только изменённый лист. Неизменённые секции, группы и соседние слои сохраняют DOM identity; структурные изменения, секционные props и `_frames` имеют безопасный секционный/полный fallback. Редактор включает incremental-режим для GeoEdit и inspector mutations, а временная AI-подсветка очищается отдельно.
- Шрифты: Google Fonts link меняется только при новом `href`; подтверждённые `document.fonts.load` не запускаются повторно; `@font-face` style переписывается только при изменении CSS. Инспектор уже обновляет значения точечно через `wireInspector`, без обязательного ремоунта на input-событиях.
- Проверка: `ui_renderer_incremental_test.py` подтверждает leaf-only patch, token-only patch без DOM-замен, fallback для структуры/`_frames` и p95 9.5мс на одной Source Import секции с 600 слоями (бюджет <150мс). `ui_renderer_frame_test.py`, `ui_editor_test.py`, engine regression и общий autosave longtask-тест зелёные.
- Остаток: подготовка diff всё ещё O(размер IR): renderer делает `structuredClone` и строит строковые fingerprints всего дерева. DOM/layout hot path устранён; дальнейшее снижение CPU и памяти требует immutable mutation metadata или передачи changed paths из store, а не догадок по объектам, мутируемым in-place.

### 2.4 Autosave: уйти от O(весь проект) на каждое сохранение (P1)
- Фронт: глубокий обход + stringify + синхронный `localStorage.setItem` в idle-слоте (`serialize.ts:160-194`).
- Бэк: полная сериализация + двойной SHA-256 + обход taste-profile всех нод под глобальным `BEGIN IMMEDIATE` (`project_store.py:239-281, 393-415`). Бюджет «autosave p95 ≤ 250мс» задокументирован, но не проверяется (`perf_scale_test.py:12-16`).
- Сделать: бэк — инкрементальные записи (дельта по нодам) или хотя бы вынести taste-profile/prompt-events из горячего пути; фронт — async Clipboard/IndexedDB вместо синхронного LS; добавить assert бюджета в перф-тест.
- Эффект: снимает фризы при активном редактировании больших проектов.

### 2.5 Загрузка приложения без фриза на старом localStorage (P1)
- Сейчас: легаси-блоб ≥400КБ синхронно `JSON.parse`-ится до первой отрисовки (замер в комментарии: 18МБ → FCP 3.2с; `store.ts:571`, `serialize.ts:585-599`).
- Сделать: скелет-экран + перенос парсинга в `requestIdleCallback`/воркер; миграцию легаси-данных — один раз, с индикатором.

### 2.6 Тёплые CLI-сессии и кэш промптов (P1)
- `build_system_prompt` перечитывает 4 файла с диска на каждый LLM-вызов (`llm_client.py:333-343`) → memoize по mtime.
- Каждое обращение к Claude = новый процесс `claude -p` (холодный старт JS-рантайма); Codex — эфемерный тред + `mcp.refresh()` с полным stop/респавном всех MCP-серверов перед каждым тредом (`main.mjs:730`, `mcp-manager.mjs:69`).
- Сделать: кэш промптов — сразу; для Codex — не пересоздавать MCP при живых серверах; для Claude — опциональный персистентный headless-режим.
- Эффект: −1–3с на каждый вызов агентов, меньше «почему думает так долго».

### 2.7 Мелочи бэкенда (P2)
- `cache_store`: глобальный lock + новое SQLite-подключение + миграция на каждую операцию + двойное хэширование (`cache_store.py:43,165-179,293-299`) → connection-per-thread + single hash.
- Финальный поллинг source-import глубоко копирует весь multi-МБ результат (`server.py:930-936`) → отдавать ссылку/блоб.
- Таймеры MotionDesign-нод поллят каждые 30с бесконечно, даже когда нода не на экране (`flow/store.ts:1919-1976`) → поллить только видимые/активные.

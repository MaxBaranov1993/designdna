# Каталог стилей и предметных паттернов

Авторская рабочая классификация для генератора, а не рейтинг трендов 2026 года. Стиль — комбинация решений, не качество само по себе. Семейства ниже допустимы только в свободных осях выбранной DS; если DS фиксирует внешний вид, выбирается подходящая композиция внутри неё.

## 1. Выбирать сначала сценарий

```text
Задача человека
  → тип поверхности и содержание
  → закреплённые ограничения DS/проекта
  → подходящая плотность и паттерн взаимодействия
  → визуальное направление в оставшихся свободных осях
  → рендер, проверка и адресная доработка
```

Не начинать с «сделать bento», когда ещё неизвестно, какие объекты человек сравнивает.

## 2. Шестнадцать семейств

| Семейство | Когда уместно | Приёмы, которые несут смысл | Типичный провал / условие отказа |
|---|---|---|---|
| Спокойный продуктовый минимализм | Формы, настройки, кабинеты, инструменты | Ясная шкала текста, компактная навигация, воздух вокруг групп | Бесцветный каркас без приоритетов или чрезмерные поля между рабочими данными |
| Информационный / enterprise | Админка, аналитика, операции | Сравнимые колонки, видимые фильтры, data hierarchy, экономная плотность | Карточка на каждый показатель; микротекст; декоративные графики |
| Search-first / marketplace | Недвижимость, услуги, товары, вакансии | Поиск, фасеты, сравнимые атрибуты, фото объекта, сохранение выбора | Рекламный hero перед полезной выдачей; скрытые цены и условия |
| Editorial / типографический | Журнал, статья, исследование, портфолио текста | Выразительная иерархия, удобная строка, подписи и авторство | Газетные линии и serif без редакционного содержания |
| Swiss / сеточный | Каталог культуры, архив, B2B-коммуникация | Сильное выравнивание, модульная сетка, точные масштабы | Мелкие uppercase labels и нумерация, не отражающая структуру |
| Product-led / демонстрационный | SaaS landing, инструмент, сложная услуга | Реальный результат/демо, сценарий использования, конкретное преимущество | Сфабрикованный dashboard, логотипы клиентов и показатели |
| Luxury / сдержанный предметный | Архитектура, предметы, премиальный сервис | Качество фото, точные пропорции, ограниченная типографическая выразительность | Бежевый фон, тонкий serif и почти невидимый текст без причины |
| Organic / материальный | Еда, интерьер, ремесло, природный контекст | Фактура предмета, естественный свет, предметная палитра | Случайные blobs и листочки вместо реального продукта |
| Playful / иллюстративный | Обучение, игры, семейный продукт | Понятные иллюстрации, дружелюбная лексика, обратная связь | Infantilization взрослой аудитории, emoji вместо иконок, хаотичные радиусы |
| Neo-brutal / плакатный | Креативные события, независимые марки | Контраст, выразительный контур, сильный заголовок | Толстая рамка на каждом utility-контроле; неудобные формы |
| Industrial / технический | Производство, оборудование, инженерные инструменты | Чертёж/схема, измерения, материал, ясная спецификация | Фиктивная консоль, «SYSTEM // ONLINE», бессмысленные метрики |
| Soft / pastel | Спокойные consumer-продукты при соответствующем бренде | Мягкие поверхности, уверенный текстовый контраст, ясные действия | Серый текст на пастельном фоне, отсутствие смысловой иерархии |
| Bento / модульная композиция | Обзор разных по важности возможностей или объектов | Размер плитки отражает значение/объём; каждый модуль содержит полезный объект | Универсальные 6 плиток, несвязанные мини-диаграммы и бесконечные cards-in-cards |
| Glass / многослойный | Overlay над картой/медиа, spatial tool, нужные прозрачные панели | Прозрачность объясняет слой, solid fallback, стабильный contrast | Blur всей страницы, слабая читаемость, тяжёлая перерисовка |
| Immersive / 3D / motion-led | Кампания, демонстрация предмета, игровой бренд | Один осмысленный интерактивный эпизод, обычная навигация и fallback | Scroll hijacking, долгий preloader, анимация вместо содержания |
| Retro / Art Deco / исторический | Событие, культурный проект, бренд с такой идентичностью | Согласованная графика эпохи и современная читаемость контролов | Орнамент мешает чтению; эклектика из несовместимых периодов |

Dark/light, высокая/низкая плотность и reduced motion — независимые оси. Dark mode не равен «техническому стилю»; bento — прежде всего композиция, не палитра.

## 3. Минимальная карточка направления

До IR сформулировать: название; кто и что делает; основная композиционная идея; что привязано к предмету; плотность; роль изображений; fixed/free axes; один компромисс; условия mobile; критерий, по которому отвергаем вариант.

Пример для freeform-каталога интерьерных предметов:

```text
Направление: «Материал крупным планом».
Задача: выбрать стул по материалу, размеру и цене.
Композиция: фильтры и сравнимый каталог; крупный кадр материала на detail.
Характер: естественный свет и ясные технические подписи.
Плотность: balanced; на detail больше воздуха вокруг предмета.
Особенность: связать фото фактуры с образцами материала.
Компромисс: нужны качественные реальные фотографии.
Mobile: фильтры в sheet, выбранные параметры видны, свойства доступны текстом.
Отказ: если фото нет, не имитировать премиальность пустым огромным hero.
```

Эта карточка — текстовый sidecar. Она не заменяет текущую `design-brief/1.0` и не добавляет в неё неизвестные поля.

## 4. Рецепты по типу поверхности

| Тип | Основная структура | Обязательные состояния | Что не добавлять по умолчанию |
|---|---|---|---|
| Лендинг | Конкретное предложение → демонстрация/объяснение → применимые условия → действие | Доступность CTA, отправка формы, ошибка, успех | FAQ, тарифы, отзывы и логотипы без соответствующих данных |
| Поиск/каталог | Запрос/фасеты → результаты → сортировка/сравнение → detail | Loading, 0 результатов, выбранные фильтры, сохранение/удаление | Гигантский hero и рекламные metrics перед выдачей |
| Карточка объекта | Медиа → ключевые свойства → цена/условия → действие → уточнения | Вариант недоступен, загрузка медиа, подтверждение выбора | Дублирование CTA в каждом абзаце, скрытые обязательные условия |
| Бронирование/checkout | Параметры → контактные данные → обзор условий → подтверждение | Ошибка поля, изменение доступности, pending, успех | Отвлекающий motion, выдуманная срочность, неожиданные доплаты |
| Dashboard | Вопросы пользователя → ключевые сигналы → детализация → действие | Нет данных, диапазон дат, stale data, ошибка загрузки | Произвольные KPI и бессодержательные sparklines |
| Настройки/форма | Логические группы → необходимые поля → сохранение/сброс | Unsaved, field error, saving, saved, unavailable | Hero, иллюстрация на половину экрана, вторичные CTA как primary |
| Редактор/canvas | Рабочая область → инструменты → свойства выбранного → история | Nothing selected, selection, dirty, saving, undo, error | Исчезающие инструменты, gesture-only управление, анимация каждого узла |
| AI workspace | Задача/контекст → выполнение → результат/источники → apply/feedback | Streaming, stop, partial, retry, preview, applied, undo | Фальшивые проценты, fake citations, «AI» на каждом badge |
| Статья/журнал | Заголовок и контекст → читаемый материал → связанные темы | Длинный заголовок, media fallback, navigation | Требование заполнить всю desktop-ширину текстом |
| Социальная лента | Объект контента → автор/контекст → доступные действия | Loading, empty, error, edited/deleted, privacy | Engagement-приёмы, не связанные с задачей продукта |

## 5. Примеры «плохо → хорошо»

### Недвижимость с выбранной DS

**Плохо:** фиолетовый hero «Дом вашей мечты», три карточки преимуществ, новый шрифт и новые карточки жилья, хотя подключена корпоративная DS.

**Хорошо:** зарегистрированный search/filter pattern, точный мастер property card, единый порядок цены/площади/адреса, допустимый map/list layout. Если DS содержит только карточку, генератор не рисует новую форму в strict; отмечает отсутствие search pattern. Композиция и текст остаются предметными.

### B2B-кабинет

**Плохо:** приветственный баннер, четыре случайных KPI, пустой линейный график, бессодержательные «активности».

**Хорошо:** список задач с понятным статусом и ближайшим действием, фильтры, компактная детализация выбранной задачи. Если количественных данных нет, не создавать цифры ради визуального баланса.

### Лендинг мастерской без DS

**Плохо:** «Преобразуем ваши идеи», градиентный шар, три иконки и выдуманные 10 000 клиентов.

**Хорошо:** конкретный предмет работы, реальные материалы/услуги из брифа, условия заказа, полезное действие «Обсудить размеры». При отсутствии фото — оформленное место под снимок с art direction и honest preview-статусом.

### Система на Inter с фиолетовым accent

**Плохо:** заменить Inter и палитру, потому что «так не будет AI slop».

**Хорошо:** сохранить DS, улучшить порядок информации, тексты, расстояния между группами и состояние ошибки доступными средствами. Самостоятельная визуальная новизна не является целью strict-режима.

## 6. Диагностика нейрослопа

Смотреть не на отдельный цвет, а на сочетание повторяемых проблем:

1. **Перестановка бренда:** после смены названия и отрасли композиция и тексты почти не требуют изменений.
2. **Контент для заполнения:** метрики, отзывы, диаграммы и features появились без предметной необходимости.
3. **Одинаковая драматургия:** у формы, журнала и каталога одинаковые hero → features → metrics → CTA.
4. **Декорация без функции:** pill, номер, sparkles, grid background, border или hover присутствуют потому, что «так красивее».
5. **Новый антишаблон:** каждый проект становится бежевым editorial или чёрным acid-tech независимо от брифа.
6. **Неполный продукт:** красивый happy path, но нет ошибок, выбранных состояний и продолжения сценария.

Контрмеры: удалить неподтверждённый контент; восстановить предметную структуру; выбрать функциональный UI pattern; использовать реальные tokens/masters; отрендерить длинные и пустые состояния. Не лечить slop добавлением другой декоративной стилистики.

Повторение мастеров в одной продуктовой семье — достоинство. Проверка на однообразие сравнивает независимые брифы без общей DS, а не разные экраны одного бренда.

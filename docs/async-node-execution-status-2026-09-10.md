# Независимые фоновые операции нод

Запрос: операции продолжаются в исходных листах и нодах при навигации. Запуск,
отмена, ошибка и завершение одной операции не меняют соседние задачи. Явные
провода и Page Bridge сохраняют своё назначение. Удаление ноды или замена
её входов по-прежнему запрещают применение устаревшего результата.

Подтверждённые причины: навигация вызывала общую отмену `leaveGraph`, runtime
и контроллеры использовали только числовой ID ноды; адресная отмена могла
перезапускать общий Python-воркер. Desktop fetch не передавал AbortSignal.

Условия готовности:
- результаты, прогресс, отмена и история принадлежат исходному листу;
- очередь и транспорт не останавливают соседние запросы;
- Source Import можно адресно отменить, его прогресс доступен под нагрузкой;
- регрессионные проверки нескольких листов с одинаковыми ID;
- сборка и проверка Electron в отдельном профиле, без изменения рабочих данных.

Статус: реализовано, проверено и запущено с пользовательским профилем 2026-09-10.

Проверки:
- Frontend: 182 теста; desktop: 366; Python: 1017, ещё 50 subtests, 1 skipped.
- Svelte: 0 ошибок и 0 предупреждений; production build и ruff прошли.

  отмена одного импорта не прерывает соседние запросы.
- Упакованный Electron, отдельный профиль: одинаковые ID генераторов в двух
  листах, ответы в обратном порядке, неизменность третьего листа, отмена скрытой

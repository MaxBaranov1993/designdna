## Исправление

- SQLite сохраняет исходные снимки, даже когда blob-offload недоступен, не успел завершиться или пропускает небольшой data URL. localStorage остаётся компактным кэшем.
- После AI-доработки Source повторно сохраняются снимки окончательного ответа: транспорт может развернуть ссылки обратно в inline-изображения.
- Генератор завершает необходимое ревью перед публикацией и не запускает вторую операцию поверх занятой ДС. Ошибка ревью сохраняется в диагностике.
- Старый черновик без снимков останавливается до вызова vision-модели с конкретной инструкцией обновить Source и синхронизировать UI Kit.

## Проверено

- 140 frontend-тестов прошли; отдельная проверка подтверждает получение варианта после успешного ревью/публикации.
- `build:desktop`: 0 ошибок и 0 предупреждений Svelte.
- Изолированный Electron: снимок переживает SQLite save/reload; генератор показывает причину отсутствия evidence без попытки публикации пустого черновика.
- Браузерная регрессия `ui_storage_compaction_test.py` на временной БД прошла.
- Открытый пользовательский Electron загрузил исправленный frontend. Сравнены и сохранены рёбра графа, блоки Source, IR редактора и варианты генератора. Диагностика проблемного генератора обновлена без вызова модели.

## Оставшееся восстановление данных

Утраченные снимки старого импорта не восстановлены. Найденные резервные захваты отличаются по дате, размерам и содержимому; подставлять их к текущим мастерам нельзя. Для проверки и публикации этого UI Kit нужен новый Source Import с текущего сайта и пересборка. Решение об обновлении содержимого запрошено у пользователя.

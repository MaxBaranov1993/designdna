# Тестовые брифы для спайка (go/no-go)

Прогоняем каждый бриф через Kimi K2.5 и qwen3-coder-plus, по 3 генерации (температура 0.7 / 0.9 / 1.0).
Критерии прохождения спайка:

1. **Валидность IR** — ≥90% ответов проходят `validate.py` без repair.
2. **Repair** — qwen3-coder-plus чинит невалидный IR за ≤2 попыток в ≥95% случаев.
3. **Качество** — слепая оценка рендеров: ≥7/10 по шкале «похоже на работу дизайнера» в ≥50% вариантов.
4. **Консистентность** — все секции варианта визуально из одной системы (субъективная проверка + единые токены).
5. **Critic** — после critic-прохода скор растёт минимум на 1 балл в ≥30% случаев.

## Брифы (нарочито разных ниш и стилей)

### B1 — SaaS, минимализм
«Лендинг для SaaS-платформы аналитики маркетинга. Аудитория — CMO среднего бизнеса. Тон: уверенный, минималистичный, светлая тема, много воздуха. Нужны: hero с продуктовым скриншотом, фичи, метрики клиентов, тарифы, FAQ, CTA.»

### B2 — Кофейня, тёплый
«Сайт спешелти-кофейни в Москве. Тёплая палитра (кремовый, коричневый, терракота), уютно, серифная типографика. Секции: hero с фото интерьера, меню (карточки), о нас, отзывы, контакты с формой бронирования столика.»

### B3 — Финтех, тёмный
«Лендинг финтех-приложения для инвестиций. Тёмная тема, неоновый акцент, доверие + технологичность. Hero, как это работает (шаги), цифры, сравнение с банками, отзывы, тарифы, форма заявки на ранний доступ.»

### B4 — Студия дизайна, брутализм
«Портфолио-лендинг независимой дизайн-студии. Брутализм: крупная типографика, ч/б + один кислотный акцент, видимая сетка. Hero-манифест, избранные проекты (галерея), услуги, команда, контакты.»

### B5 — Образование, playful
«Лендинг онлайн-школы программирования для подростков. Ярко, дружелюбно, скруглённые формы, иллюстрации. Hero, курсы (карточки), как проходит обучение, отзывы родителей, тарифы, форма записи на пробный урок.»

### B6 — Компонент, а не страница (проверка гранулярности)
«Сгенерируй ТОЛЬКО секцию pricing: 3 тарифа для облачного хранилища, средний выделен, переключатель месяц/год. Светлая тема, корпоративный стиль.» — ожидаем tree из одной секции.

### B7 — Адверсариальный (проверка устойчивости схемы)
«Сделай лендинг с анимированным 3D-фоном, параллаксом и видеоплеером» — модель должна остаться в рамках библиотеки блоков (медиа-ассеты через imagePrompt), а не выдумывать типы.

**Вердикт: GO.** Схема и промпт работают; связка qwen3.7-max + k3 пригодна для MVP.
86% первопроходной валидности компенсируется 100% repair за 1 попытку — в продакшене
repair-loop обязателен (он и планировался). До фазы 1 рекомендуется подтянуть схему по
типичным ошибкам: (1) `props` сделать default {} вместо required или явно писать в промпте
«props обязателен, минимум {}»; (2) в element допустить `avatar`-элемент в card-children
(модель его ожидает); (3) tone: дописать 'secondary' в enum либо явный запрет в промпте.
Это поднимет первопроходную валидность выше 90%.
